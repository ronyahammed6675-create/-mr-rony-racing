# MR RONY RACING

A mobile-friendly 3D motorcycle highway game built with HTML, CSS, JavaScript, and Three.js. The bike, rider, road, roadside scenery, traffic, engine, music, and effects are created procedurally; the only runtime dependency is Three.js from jsDelivr.

## Run locally

From this folder, start a local web server:

```sh
python3 -m http.server 8000
```

Open `http://127.0.0.1:8000/` in a modern browser with WebGL enabled and an internet connection for Three.js.

## Controls

- Touch and hold **LEFT** or **RIGHT** to steer; touch and hold **ACCELERATE** to build speed and **BRAKE** to slow down.
- On a keyboard, use the arrow keys or WASD. Hold **Up/W/Space** to accelerate and **Down/S** to brake. Press **P** or **Escape** to pause or resume.
- Use the top-right sound button to mute or enable synthesized music and sound effects.

Choose Rookie, Pro, or Elite in the garage. Best score is stored in browser local storage.
